# 🧮 Divide 2 Numbers

A simple web application built with **HTML**, **CSS**, and **JavaScript** that divides two numbers and displays the result instantly.

## ✨ Features

- ✅ Divide two numbers
- ✅ Input validation
- ✅ Prevent division by zero with an alert message
- ✅ Clean and responsive user interface
- ✅ Built with Vanilla JavaScript (No libraries)

## 📖 How It Works

1. Enter the first number.
2. Enter the second number.
3. Click **Calc**.
4. The application displays the division result.
5. If the second number is **0**, an alert message appears:
   > "You can't divide by zero."
